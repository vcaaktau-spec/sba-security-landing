# BRIEF — SBA Security сайт 2026: интерактивный подбор оборудования

## Контекст

Существующий проект: `toosba.kz` — лендинг компании SBA Security (Актау, Казахстан), которая продаёт и монтирует охранные системы (видеонаблюдение, СКУД, сигнализация, сети). Стек: React + Vite + Tailwind/shadcn, Clerk (авторизация), Neon Postgres + Drizzle ORM, Vercel (хостинг + serverless `api/`). Это **не greenfield** — большая новая фича поверх существующей кодовой базы. Не предлагать переписывание того, что не входит в объём ниже.

На сайте уже есть рабочий квиз-калькулятор (`src/components/Calculator.tsx`) — пошаговый расчёт стоимости монтажа видеонаблюдения по абстрактным тирам (кол-во камер, разрешение, монтаж). Недавно для него была подготовлена (но пока не включена) инфраструктура автообновления цен с сайта поставщика barlau.kz — она остаётся как есть, вне объёма этой фичи.

## Идея

Главная страница переделывается полностью: hero → блок "боли" (реальные примеры последствий отсутствия/экономии на видеонаблюдении, мировая статистика/кейсы) → блок преимуществ SBA → **два пути расчёта**.

### Путь 1 (новый, главный): интерактивный подбор оборудования

Пользователь выбирает один из двух режимов:

- **С AI** — отвечает на наводящие вопросы (сколько камер, где ставить — улица/помещение/периметр, что важно — ночная съёмка, распознавание лиц, дальность обзора и т.п.). Ответы + данные каталога уходят в Gemini API, который возвращает 2-3 конкретных набора товаров из каталога на выбор.
- **Вручную** — пользователь открывает каталог и сам выбирает нужные позиции.

Оба режима ведут в общую **корзину** (без оформления покупки — только расчёт). Из корзины считается смета/КП с учётом монтажных работ (переиспользуя часть текущей ценовой логики монтажа/кабеля/HDD), с обязательной оговоркой "цены ориентировочные, точная стоимость уточняется при выезде специалиста", и генерируется скачиваемый документ (PDF-пайплайн на jsPDF+html2canvas уже реализован для старого калькулятора — можно переиспользовать паттерн).

### Путь 2 (существующий, второстепенный): старый калькулятор

`Calculator.tsx` остаётся без изменений по содержанию — просто становится второстепенной опцией "быстро посчитать монтаж", без привязки к конкретным товарам каталога.

## Что нужно построить

- Каталог оборудования: модель данных (Drizzle/Neon) — категория, фото, название, характеристики, базовая цена "как есть". Наполнение каталога данными — открытый вопрос (у barlau.kz нет машиночитаемого экспорта, только страницы товаров с публичной ценой без логина).
- Корзина (клиентское состояние, возможно с сохранением между визитами).
- Пересчёт сметы по товарам из корзины + монтажные работы.
- Серверная интеграция с Gemini API (нужен `GEMINI_API_KEY` как переменная окружения — сам ключ не пишем в план и не запрашиваем в чате).
- Генерация КП/сметы (переиспользуя существующий PDF-пайплайн).
- Полный визуальный редизайн главной страницы и связанных экранов в стиле Linear — минимализм, но премиально; сохранить текущую тактическую айдентику (blueprint-сетка, моноширинные лейблы, красный акцент).

## Аудитория

Двойная: частные лица/малый бизнес — и снабженцы/procurement крупных компаний (нужна убедительность фактами и официальный формат КП).

## Известные напряжения для synthesis/Tensions

- Нужен ли Gemini на MVP, или можно запустить без AI-режима первой итерацией.
- Как наполнять каталог данными без машиночитаемого фида от поставщика.
- Объём редизайна за один заход (вся главная целиком vs по частям).
- Как показывать "примерные" цены, не вводя клиента в заблуждение (юридический/доверительный риск).
- Как это стыкуется с уже добавленным (но неактивным) кэшем цен barlau.kz под старый калькулятор — не дублировать усилия.

## Не входит в объём

- Изменение содержательной логики старого `Calculator.tsx`.
- Онлайн-оплата/чекаут (оборудование не продаётся отдельно от монтажа).
- Активация парсинга barlau.kz (это отдельная, уже начатая ветка работы).
